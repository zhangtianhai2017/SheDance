# 生物力学逆向 · 无 RL · 自建 — 总体路线

> 核心路线文档。2026-06-03 决策:**放弃 RL 训练肌肉,改用计算生物力学的逆向方法**确定性地
> 从给定舞段算出肌肉激活。理由见下。关联:[compile_bottleneck_findings.md](compile_bottleneck_findings.md)。

## 为什么转(RL 路否决)

1. **算力不可行**:从零肌肉 RL 需千万~十亿步,本机 ~千步/2h → 几百年(见 compile_bottleneck_findings)。
2. **RL 不一定像人**:RL 只优化奖励,会发明"能拿分但不像人"的发力方式(奖励黑客/诡异步态)。
   舞蹈要"人看着自然",这是硬伤。
3. **人体怎么发力,科学早研究透了**——直接用,不必让 RL 重新(且更差地)发明。

## 路线(确定性、无训练、本机可跑)

```
① 参考舞段 → 关节角轨迹 qpos        【已有:AIST++ Pop 重定向到 MyoFullBody】
② 平滑 + 数值求导 → qvel, qacc
③ 逆动力学(MuJoCo mj_inverse)→ 每帧所需广义力(关节力矩)   【确定性物理】
④ 肌肉冗余求解(每帧优化):力矩 → 肌肉激活
     min Σ aᵢ² (Crowninshield 最小努力准则 → 复现真人招募)
     s.t. 肌肉力经力臂产生所需力矩, a∈[0,1], 含激活/收缩动力学
⑤ 激活轨迹 → 驱动 MyoFullBody 播放 → 渲染 → 烘焙进 UE/MetaHuman
```

对应成熟科学:OpenSim **CMC / Muscle Redundancy Solver / Static Optimization**;Crowninshield 最小疲劳准则。

## 保留的东西(用户明确)

- **思想**:视频/参考给主干,肌肉补真实发力与细节("舞者内生模型");
- **肌肉**:全程真实肌肉驱动(算出真实激活,不退化成力矩玩具);
- **自建**:不依赖 MuscleMimic 的 RL;我们自己写逆向求解。

## 优于 RL 的点

| | RL | 生物力学逆向 |
|---|---|---|
| 像人 | 可能诡异 | 准则即"像人" |
| 训练/算力 | 千万-十亿步,本机不可行 | 无训练,每帧小优化,本机轻松 |
| 编译墙 | 撞 | 不存在 |
| 可控/自建 | 依赖框架 | 自己写 |

## 已知的坎(都有标准解法)

1. **动力学一致性**:参考不完全物理自洽 → ID 在根部出"残差力"。解法:OpenSim **RRA**(残差消减)
   先小修参考使自洽,再求肌肉。
2. **它复现给定动作**(非反应式策略)——但这正是目标("把视频舞段变肌肉驱动"),无需反应式 RL。
3. 肌肉冗余是病态/瞬时解 → 可加**协同(synergy)约束**或时序平滑,更像人、更稳。

## 与"内生模型 / 协同分级"对接

- ④ 的目标函数可换成**带舞者习惯先验**的(不同角色不同发力风格);
- 可把激活约束在**低维肌肉协同空间**(人体已研究的 synergy 基)→ 更真实 + 更省;
- 这就是之前"L1/L2/L3 分级 + 内生模型"在无 RL 框架下的落地。

## 分阶段(自主推进,路线节点同步)

1. **阶段1 — ID 原型**:已有 Pop qpos → 平滑求导 → `mj_inverse` → 出每帧所需力矩。验证管线通。
2. **阶段2 — 肌肉冗余求解**:力臂矩阵 + 肌肉力模型 + 每帧 QP(min Σa²)→ 激活轨迹。
3. **阶段3 — 播放/渲染**:用激活驱动 MyoFullBody → mp4,看是否人样地跳 Pop。
4. **阶段4 — 一致性+真实感**:RRA 残差消减、协同约束、时序平滑。
5. **阶段5 — 手模块 + UE 烘焙**。

> 本路线**绕开了编译墙、吞吐墙、RL 不自然**三大问题,且全程本机可跑。
