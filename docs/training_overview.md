# 训练框架与目标总览（S1：让肌肉身体跳舞）

> 普通技术文档，记录当前肌肉策略训练这条线的框架与预期。非 Agent 必读。
> 最近更新：2026-06-01

## 一句话

让一具 **354 块肌肉**（含手指版 416）的 MyoFullBody 身体，靠**物理 + 肌肉发力**去逼近一段
站立的 Pop 舞蹈参考动作；奖励就是"跳得像不像"。训得越久，越从乱动逼近到真跳。
**不是动画播放，是肌肉真实驱动的运动。**

## 注意 / 已知

- **首迭代极慢**：13.7M 网络 + 2048 肌肉环境的 XLA/warp 首次编译很重，加上近满显存
  （~44.9/46 GB），首个迭代/checkpoint 可能十几分钟后才出。GPU 100% = 在真算，不是卡死。
- **显存压力**：2048 环境接近 A6000 上限；若迭代过慢可降到 1024。
- **吞吐/ETA**：需等第一个 checkpoint 出来实测后才能可靠估算（`2.048B步 ÷ 163840步/迭代
  ≈ 1.25万迭代`是全量上限，实际只跑其中一段）。
